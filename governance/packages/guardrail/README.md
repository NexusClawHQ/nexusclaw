# @agent-governance/guardrail

Guardrail rule engine: L0–L4 risk matching and assessment with pluggable rule loading.

Part of the [NexusClaw Community](https://github.com/NexusClawHQ/nexusclaw)
governance kernel (`governance/` pnpm workspace — 9 Apache-2.0 packages).
Apache-2.0 licensed.

## Install

```sh
npm install @agent-governance/guardrail
```

> Published to npm at 0.1.0 — the nine kernel packages version together
> (fixed changesets group). The 0.1.0 tarball still carries this older
> "not yet published" note; the correction ships from the next release on.
